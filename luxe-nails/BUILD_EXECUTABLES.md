# Build Release Artifacts

See the [root README](../README.md) for product overview and [INSTALLERS.md](INSTALLERS.md) for packaging commands.

- macOS: `./build-mac.sh` reads `VERSION`
- Windows: `.\build-windows.ps1` reads `VERSION.windows` (falls back to `VERSION`)
- Optional icons: `assets/icons/app.icns` or `assets/icons/app.ico`
